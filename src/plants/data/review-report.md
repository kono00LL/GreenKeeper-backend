- 春羽：Thaumatophyllum bipinnatifidum → Philodendron bipinnatifidum。Pl@ntNet 使用 Philodendron bipinnatifidum；园艺来源也以该名称展示。原候选 Thaumatophyllum bipinnatifidum 保存在本核对记录，运行时不做异名匹配。
- 西瓜皮椒草：Peperomia argyreia → Peperomia argyreia。园艺来源由 Peperomia argyreia 地址重定向至 Peperomia argyraea；保留 Pl@ntNet 所用拼写及两侧原文，待分类学拼写复核。
- 散尾葵：Dypsis lutescens → Dypsis lutescens。园艺来源标题采用 Chrysalidocarpus lutescens，Pl@ntNet 使用 Dypsis lutescens；来源页面由旧名地址重定向，保留名称差异。
- 矮牵牛：Petunia × atkinsiana → Petunia × atkinsiana。园艺来源使用 Petunia x hybrida；需另行确认接受名与异名关系，暂不发布。
- 虹之玉：Sedum rubrotinctum → Sedum × rubrotinctum。Pl@ntNet 名录保留杂交符号 ×，本地相应采用 Sedum × rubrotinctum；养护物种资料尚待核实。
